# Pop-Fish

**Zotero 里的期刊情报站。** 为文库中的每篇文献补上期刊指标与投稿风险信号，并直接显示在条目列表里。

- **影响因子**：最新 JIF 与五年 JIF
- **JCR 分区**：Q1–Q4
- **中科院分区**：1–4 区
- **期刊预警**：命中中国科学院国际期刊预警名单（2025 版，130+ 种）或 predatoryjournals.org 掠夺性期刊目录（2025 版，约 2,800 种）时标红提示

数据来自 [文献泡泡（BytesLink）期刊开放 API](https://byteslink.cn/docs/open_api/index.html)。

---

## 安装

1. 从 [Releases](https://github.com/moonbowterfly/pop-fish/releases/latest) 下载 `pop-fish-x.y.z.xpi`
2. 打开 Zotero → **工具 → 插件**
3. 右上角齿轮 → **Install Plugin From File…**，选择刚下载的 xpi
4. 重启 Zotero

首次启动会弹出提示并自动打开设置面板，粘贴你的文献泡泡 API Key（网站「用户中心 → 我的 API」生成，明文只显示一次）。

从旧版升级会保留插件 ID、API Key 与已有显式设置。**新装默认关闭自动查询；旧版若已显式开启，升级不会强制关闭**，请在设置中核对开关与预算。旧 schema 1 缓存会按记录原始期刊名迁移为 schema 2。

## 使用

### 首次填充数据（v0.2.1）

1. 先在 Zotero 主窗口选择要填充的文库、分类或搜索结果。
2. 打开 Pop-Fish 设置，输入 Key 后点击「测试连接」；测试通过会保存输入的 Key，失败则保留输入。
3. 点击「填充当前列表（先确认费用）」，核对去重后的期刊数与请求数上限，确认后获取数据；结果自动显示，无需重启。

连接检测只查 Nature，不能代表已经查询了文库。该已付费查询的样例会复用到缓存，但其余期刊仍需明确确认后查询；不自动开启收费的浏览补全。列中的「待查询」「未配置 Key」「无期刊名」「查询失败」「预算已用完」解释未显示数字的原因，不再静默空白。「—」表示未收录/名称未匹配或指标缺失；附件/笔记没有期刊列数据。

### 条目列表列

装好后条目列表会多出四列：**影响因子 / JCR 分区 / 中科院分区 / 期刊预警**。表头右键可打开列选择器，自由隐藏、排序、调整宽度。

列默认**不会自动联网**。只有在设置里显式打开「浏览时自动补全」后，缺失或过期的期刊才会在浏览时入队查询；每次会话最多自动查询 40 个期刊（可在设置里改为 0–400）。查询结果按期刊名缓存在本地，同一期刊在有效期内只查一次。排序会让 Zotero 读取当前视图的全部行，因此自动预算在入队时就预占，1000 行排序也不会突破上限。

### 右键菜单

选中条目后右键：

| 菜单项 | 作用 |
|---|---|
| 更新期刊数据 | 强制重查所选条目的期刊，并把结果写进条目的「其他（Extra）」字段 |
| 复制期刊快照 | 把所选条目的完整指标复制成 Markdown，便于粘贴到笔记或聊天 |
| 期刊工具 → 体检当前分类 | 批量查询当前分类下所有条目的期刊（优先用缓存） |
| 期刊工具 → 体检整个文库 | 同上，范围是整个文库 |
| 期刊工具 → 清除期刊缓存 | 清空本地缓存，下次重新拉取 |
| 期刊工具 → Pop-Fish 设置… | 打开设置面板 |

分类上右键还有「体检当前分类」的快捷入口。

### 写入 Extra 的格式

```
[Pop-Fish] JIF=56.1; JIF5=56.7; JCR=Q1; CAS=1; Warning=no; Metrics=2026-10-22; Risk=2026-10-22
```

用方括号而不是 `Key: value`，避免被 Zotero 当成自定义字段。命中预警时 `Warning=预警+掠夺`。指标与风险各自带日期（`Metrics=` / `Risk=`），半更新不会假装全部刚查过。每次更新只替换自己那一行，不动 Extra 里的其他内容；只读条目会跳过并计数。

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| API Key | 空 | 文献泡泡开放接口密钥，存于 `extensions.zotero.popfish.apiKey` |
| 条目列表列 | 全开 | 分别控制四列是否注册 |
| 浏览时自动补全 | **关** | 打开后浏览/排序才会自动入队；关闭时手动更新仍可用 |
| 每会话自动查询上限 | 40 | 0–400 个期刊；只限制自动查询，手动批量更新不受此上限约束 |
| 写入 Extra 字段 | 开 | 关闭后只在列里显示，不改动条目数据 |
| 缓存有效期 | 90 天 | 指标按年更新，90 天足够；预警名单可设更长 |
| Extra 标签 | `Pop-Fish` | 写入 Extra 时的行前缀 |

设置面板里还有「测试连接」，会用一个已知期刊探测服务并显示延迟与额度来源。它**本身消耗 1 次接口请求**，请求完成前按钮会禁用，防止连点重复扣费。

## 计费与额度

接口按**请求次数**计费，一次请求可带最多 20 个期刊名，所以插件把期刊名攒批发送：

- **完整**查询（指标 + 风险两份数据都过期）每 20 个不同期刊消耗 **2 次**请求
- 只有一份过期时只查那一个接口 → 1 次请求
- 全部命中缓存 → 0 次请求
- 两张表各自记过期时间，互不拖累
- 响应里的 `usage` 字段会显示扣费来源（免费额度 / 付费额度）

所有手动批量动作（更新所选、体检分类、体检文库）都会先做预检并弹窗确认：显示去重后的期刊数、两个接口各自缺失/过期的数量，以及按每批 20 个估算的**请求数上限**。这个数字是上限，不是账户余额，也不保证最终扣费完全一致。取消即 0 请求、0 Extra 写入；全部命中缓存时 0 请求，不弹费用确认。「更新期刊数据」是强制重查，因此总会按全量估算并确认。

失败分三类处理：401/402 会**立即停止**本次剩余批次并锁定账户一小段时间；429 全局冷却，后续操作再试（本次不会自动重试）；其余按期刊退避 60 秒。改对 Key 并成功保存后才会解除锁定。

额度耗尽返回 402，插件会提示去用户中心充值。

## 数据来源与免责声明

期刊指标与名单均来自文献泡泡开放接口的公开数据整理，版权归原发布方所有。数据仅供参考，不构成投稿决策的唯一依据。插件不会上传你的文库内容，只发送期刊名称。

## 已知限制

- 本地缓存身份是**保守**的：只做 Unicode NFKC、大小写、空白与不换行空格归一。冠词和标点保留，因此 `A/B`、`A:B`、`A B`、`B` 不会被合并；缩写与全称（如 `J. Med. Chem.` 与 `Journal of Medicinal Chemistry`）也会各存一份、各查一次。插件不内置别名表，也不会擅自把缩写等同于全称。期刊名匹配最终由服务端完成；个别期刊改名或拼写特殊时可能返回「未收录」。
- 若系统代理会接管 `api.byteslink.cn`，首次请求可能慢到数秒（实测直连约 0.13s，走代理约 4–5s）。可在 Zotero 的代理设置里给该域名加例外。
- 列排序按显示文本的字典序，`56.1` 与 `6.8` 的先后可能与数值顺序不一致；`—`（未收录）排在中文之后。
- 点击这些列排序时，Zotero 会为**当前视图的全部条目**读取列值，因此一次排序可能把整个视图里不同的期刊都排进查询队列。自动预算在入队时预占，超出后不再自动发起；需要补查时用「体检」，它会先确认费用。

## 开发

```bash
python tools/make_icons.py     # 重新生成图标
python build.py                # 打包 dist/pop-fish-<version>.xpi
node --test tests/node/*.test.cjs           # 真实源码 + 假宿主，离线
python -m unittest discover -s tests -p "test_*.py" -v   # 打包/版本守卫
```

`build.py` 使用**运行时允许清单**打包（manifest 排第一）：只收 `manifest.json`、`bootstrap.js`、`prefs.js`、`LICENSE`、`chrome/content/` 下的脚本/样式/图标/XHTML 和 `locale/<locale>/*.ftl`。临时 JSON、备份、测试、文档、凭据文件即使放在项目里也不会进包。

### 自检

插件内置端到端自检（默认关闭，开启后会消耗真实接口请求），可在无 GUI 的情况下验证整条链路（连接 → 批量查询 → 缓存 → 列文本 → Extra 行 → 菜单标签 → 设置面板）：

```
extensions.zotero.popfish.apiKey = pp_xxx
extensions.zotero.popfish.selfTestOnStartup = true
```

以 `-ZoteroDebugText` 启动 Zotero，日志里会出现一行 `[Pop-Fish] SELFTEST {...}`，包含全部检查结果。用 `extensions.zotero.popfish.seedTestItems = true` 还可以在空库里造三条演示条目，用来肉眼确认列的渲染。
